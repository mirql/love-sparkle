A tiny sparkle of love: `✨❤️ Sparkle of Love ❤️✨`, the same text byte for byte in every
language, with zero dependencies.

> [!NOTE]
> love-sparkle is 0.7: one version for every package, zero dependencies. It returns one
> string, and that is all it will ever do.

## Install

| Language | Install | Use |
|---|---|---|
| TypeScript (npm) | `npm install @mirql/love-sparkle` | `import { sparkleOfLove } from "@mirql/love-sparkle"` |
| Deno (JSR) | `deno add jsr:@mirql/love-sparkle` | `import { sparkleOfLove } from "@mirql/love-sparkle"` |
| Rust | `cargo add mirql-love-sparkle` | `mirql_love_sparkle::sparkle_of_love()` |
| Python | `uv add mirql-love-sparkle` | `from mirql_love_sparkle import sparkle_of_love` |
| Go | `go get github.com/mirql/love-sparkle/go` | `lovesparkle.Sparkle()` |

The ports: [`rust/`](https://github.com/mirql/love-sparkle/tree/main/rust), [`python/`](https://github.com/mirql/love-sparkle/tree/main/python), [`go/`](https://github.com/mirql/love-sparkle/tree/main/go).

## Share your sparkle ✨

Add your own sparkle of love: one line of kindness in a file named after you. It takes a
minute, needs no git, and makes you one of our contributors.

1. [Open a new sparkle](https://github.com/mirql/love-sparkle/new/main/sparkles?filename=YOUR-GITHUB-NAME.txt),
   put your GitHub name in the file name, and write your line.
2. Click **Propose changes**, then **Create pull request**.

The rules (kind, humble, curious; no links, no @mentions, at most 280 characters) are in
[CONTRIBUTING.md](https://github.com/mirql/love-sparkle/blob/main/CONTRIBUTING.md#your-first-pr-share-a-sparkle).
