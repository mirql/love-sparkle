# Security policy

## Reporting a vulnerability

Please **do not open a public issue.** Report it privately through GitHub:
**Security → Report a vulnerability** on this repository.

Include what you can: what you ran, what happened, what should have happened, and your
love-sparkle version and system. We will acknowledge the report, keep you updated, and credit
you in the advisory unless you prefer otherwise.

## In scope

The published packages (npm, JSR, crates.io, PyPI, the Go module) and this repo. The
packages have no dependencies and no install scripts; anything that changes that, or a
version we did not publish, is in scope.

## Supported versions

Only the latest release gets security fixes.
