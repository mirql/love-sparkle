# mirql-love-sparkle

The Python port of [`@mirql/love-sparkle`](https://www.npmjs.com/package/@mirql/love-sparkle):
a tiny sparkle of love, with zero dependencies.

## Usage

```python
from mirql_love_sparkle import sparkle_of_love

print(sparkle_of_love())
# => ✨❤️ Sparkle of Love ❤️✨
```
