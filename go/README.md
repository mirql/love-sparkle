# mirql-love-sparkle (Go)

The Go port of [`@mirql/love-sparkle`](https://www.npmjs.com/package/@mirql/love-sparkle):
a tiny sparkle of love, with zero dependencies.

## Usage

```sh
go get github.com/askaramirov/mirql-love-sparkle/go
```

```go
import lovesparkle "github.com/askaramirov/mirql-love-sparkle/go"

func main() {
	fmt.Println(lovesparkle.Sparkle())
	// => ✨❤️ Sparkle of Love ❤️✨
}
```

Releases are git tags `go/vX.Y.Z`.
